# 🚀 极速文件搜索 V2.0 - Rust完全重写版

> 基于 Tauri + Rust + USN Journal 的高性能文件搜索工具

## ✨ 特性

### 🔥 核心功能
- **USN Journal 扫描**：利用Windows NTFS的USN日志，秒级扫描整个磁盘
- **FTS5 全文搜索**：基于SQLite FTS5的高性能全文搜索引擎
- **实时文件监控**：自动监控文件系统变化，保持索引最新
- **多种搜索模式**：
  - 索引搜索（极速）
  - 实时搜索（精确）
  - 模糊匹配
  - 正则表达式

### 🎨 界面功能
- **现代化UI**：基于HTML/CSS/JS的精美界面
- **深色/浅色主题**：支持主题切换
- **高级筛选**：按文件类型、大小、时间筛选
- **批量操作**：批量重命名、删除、复制
- **收藏夹**：快速访问常用目录
- **搜索历史**：自动保存搜索记录

### ⚡ 性能优化
- **并行处理**：使用Rayon进行多线程并行处理
- **懒加载**：文件信息按需加载，减少内存占用
- **分页显示**：支持大量结果的高效展示
- **智能过滤**：自动跳过系统目录和临时文件

### 🔧 系统集成
- **系统托盘**：最小化到托盘，后台运行
- **全局热键**：
  - `Ctrl+Shift+Space`：显示迷你搜索窗口
  - `Ctrl+Shift+Tab`：显示主窗口
- **右键菜单**：集成Windows资源管理器
- **文件关联**：支持打开、定位、复制等操作

## 🏗️ 技术架构

### 后端 (Rust)
```
src/
├── main.rs          # 程序入口
├── lib.rs           # Tauri应用主逻辑
├── config.rs        # 配置管理
├── database.rs      # 数据库层 (rusqlite + FTS5)
├── scanner.rs       # USN扫描引擎
├── watcher.rs       # 文件监控
├── commands.rs      # Tauri命令接口
├── hotkey.rs        # 全局热键
└── utils.rs         # 工具函数
```

### 前端 (HTML/CSS/JS)
```
ui/
├── index.html       # 主界面
├── styles.css       # 样式表
└── app.js           # 应用逻辑
```

### 核心依赖
- **Tauri 1.5**：跨平台桌面应用框架
- **rusqlite**：SQLite数据库（支持FTS5）
- **rayon**：数据并行处理
- **parking_lot**：高性能锁
- **windows-rs**：Windows API绑定

## 📦 构建说明

### 前置要求
- Rust 1.70+
- Node.js 16+ (可选，用于前端开发)
- Windows 10/11 (USN Journal功能仅支持Windows)

### 开发模式
```bash
# 安装依赖
cargo build

# 运行开发版本
cargo tauri dev
```

### 发布构建
```bash
# 构建发布版本
cargo tauri build

# 输出位置：target/release/filesearch.exe
```

## 🚀 使用说明

### 首次使用
1. 启动应用后，点击"🔄 立即同步"建立索引
2. 等待索引完成（C盘约需1-2分钟，取决于文件数量）
3. 在搜索框输入关键词，点击"🚀 搜索"

### 搜索技巧
- **普通搜索**：直接输入文件名关键词
- **模糊匹配**：勾选"模糊"，支持不连续字符匹配
- **正则表达式**：勾选"正则"，使用正则表达式搜索
- **实时搜索**：勾选"实时"，直接扫描文件系统（较慢但最新）

### 高级功能
- **大文件扫描**：快速找出占用空间大的文件
- **批量重命名**：支持前缀+序号、文本替换等模式
- **C盘目录设置**：自定义C盘扫描范围，提高索引效率
