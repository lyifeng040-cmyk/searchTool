# 🔍 应用启动崩溃问题诊断

## 问题描述

应用编译成功，但启动时立即崩溃，退出代码：`3221225785` (0xC0000409)

## 错误代码分析

**0xC0000409** = `STATUS_STACK_BUFFER_OVERRUN`
- Windows安全异常
- 通常由以下原因引起：
  1. WebView2运行时缺失或损坏
  2. DLL加载失败
  3. 内存访问冲突

## 根本原因分析

### 🎯 高度怀疑：WebView2运行时问题

**证据：**
1. 崩溃发生在Tauri初始化阶段
2. Rust panic hook未被触发（说明崩溃在Rust层之前）
3. 退出代码0xC0000409通常与DLL加载相关
4. 检查注册表未找到WebView2安装信息

**WebView2检查结果：**
```powershell
Get-ItemProperty -Path "HKLM:\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}"
# 返回：空（未安装）
```

## 解决方案

### 方案1：安装WebView2运行时（推荐）

下载并安装Microsoft Edge WebView2 Runtime：
https://developer.microsoft.com/microsoft-edge/webview2/

### 方案2：使用固定版本WebView2

修改`tauri.conf.json`：
```json
{
  "tauri": {
    "bundle": {
      "windows": {
        "webviewInstallMode": {
          "type": "fixedRuntime",
          "path": "path/to/webview2"
        }
      }
    }
  }
}
```

### 方案3：切换到其他UI框架

如果WebView2不可用，可以考虑：
- **egui** - 纯Rust原生GUI
- **iced** - 跨平台Rust GUI
- **slint** - 声明式UI框架
